# Mistral — Open-Source Europeu

## O que é

Mistral AI é uma startup francesa (fundada por ex-Meta e ex-DeepMind) que produz modelos open-source de alta qualidade. Principal vantagem: **empresa europeia** com compliance GDPR nativo, infraestrutura EU.

## Modelos (Junho 2026)

| Modelo | Tipo | Contexto | Licença | Destaque |
|--------|------|:--------:|---------|----------|
| **Mistral Large** | Proprietário | 128K | Comercial | Frontier Mistral |
| **Mistral Medium** | Proprietário | 128K | Comercial | Custo-benefício |
| **Mixtral 8x22B** | MoE open | 64K | Apache 2.0 | MoE eficiente |
| **Mistral 7B** | Dense open | 32K | Apache 2.0 | Leve, rápido |
| **Codestral** | Code-specific | 32K | Specific | Coding otimizado |

## Diferenciais

- **GDPR-native** — Empresa e infra na Europa
- **Le Chat** (consumer product) — Alternativa europeia ao ChatGPT
- **Codestral** — Modelo otimizado para código
- **API + Self-host** — Ambos disponíveis
- **Apache 2.0** em modelos open (Mixtral, Mistral 7B)

## Quando Usar

✅ **Use Mistral quando:**
- **GDPR/compliance europeu** é requisito
- Quer modelo open **leve e eficiente** (7B)
- Código com **Codestral** (alternativa a DeepSeek Coder)
- Infra precisa estar na EU

❌ **Evite quando:**
- Quer frontier absoluto → OpenAI/Anthropic
- Contexto ultra-longo → Gemini ou Llama Scout
- Melhor coding open → DeepSeek V4 é superior
